# Airports Problem

Run `python3 main.py` and choose among the flights listed for the current city. A known city without a direct outgoing flight is rejected just like an unknown key; travel time and location stay unchanged until a valid choice is entered. Whitespace and letter case are ignored. A city with no outgoing flights ends the manual search.

The supplied Boston-New York-San Francisco-Los Angeles route takes 8 hours. Boston-Washington D.C.-Seattle-San Francisco-Los Angeles takes 13 hours. Each directed edge adds its travel time once.
